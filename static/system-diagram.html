Arsitektur · Data multi-cabang · Auth & keamanan · Alur bisnis · Realtime · Frontend · Deploy — interaktif: klik seksi di nav, hover elemen untuk detail, zoom +/-

Proses aplikasi Sukses / data OK Gate / keputusan Integrasi eksternal Database Eksternal (Google, CI)

1 · Arsitektur Infrastruktur

Alur request HTTPS end-to-end: browser → DuckDNS → nginx (TLS) → Flask/Gunicorn → MariaDB. Semua container di satu host; DB hanya ter-bind localhost.

2 · Data Multi-Cabang (1 master + N DB cabang)

Session membawa branch_code → resolve_db_name() memilih DB cabang → connection pool per DB. Tabel users/branches hanya di master.

3 · Auth & Keamanan (ISO 27001)

Login username+PIN → session cookie bpf_session (12h) + CSRF token. Aksi berisiko wajib step-up PIN (428 → /api/step-up, grant 10 min). Scoping admin per cabang.

4 · Alur Air Minum (OB → Finance)

Alur penuh: OB diunggah foto sebelum/sesudah → Finance memverifikasi (step-up PIN) → PDF Tanda Terima kop cabang → registri integritas dokumen.

5 · Alur Overtime (Google Sheets ↔ Aplikasi)

Data overtime hidup di Google Sheets; Apps Script menulis, aplikasi PULL via URL dari system_config, upsert dengan source_uid = md5(nama|submitted_at) (tahan geser baris sheet).

6 · Alur Kasbon / Klaim BBM (Approval Berjenjang)

Pasca v2.36: semua pengajuan wajib ACC Chief Driver dulu → GA → Admin. Gate 409 SUPERVISOR_APPROVAL_REQUIRED; tolak wajib alasan.

7 · Alur Kehadiran Training (Receptionis, H1/H2)

Receptionis mengisi kehadiran peserta training per tahap (H1/H2/…) — setelah aksi, list reload otomatis (fix SW v2.37.8).

8 · Realtime Notifikasi (Socket.IO)

Eventlet worker + Flask-SocketIO; room per driver & marketing; event broadcast (water_purchase_new, new_claim). Nginx proxy dengan upgrade WebSocket.

9 · Frontend SPA (Vue 3 + Pinia + Vite)

SPA statik di /app; router per role; api.js wrapper CSRF + retry; service worker v2.37.8 cache SOLO shell+asset (bypass /api/*).

10 · Kop Dokumen Per Cabang (v2.37.7)

Alamat/telepon kop tidak lagi hardcode — dibaca dari tabel branches (master), bisa diedit Admin Pusat dari UI Pengaturan → Cabang ✏️.

11 · CI/CD & Deploy

GitHub Actions (pytest + vitest + build + pip/npm audit + Trivy) → merge main → rebuild image → compose up → health check. Guard gunicorn worker (v2.37.7) menahan regresi crash-loop.
